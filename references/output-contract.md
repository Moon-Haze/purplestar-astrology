# 解读输出契约

交付给用户的解读文本按此模板组织——**章节、顺序、命名固定**，`<>` 为待填槽位。
本文件是 `SKILL.md` 指向的细则；`SKILL.md` 只留五节标题、形态清单与三条最要紧的硬约束。全盘五节之外的四种形态（聚焦 / 主题 / 流年 / 合盘）与十二宫主管领域白话对照都在本文件。

## 模板

```markdown
## 命盘解读 · <命宫主星>（<分数最高的格局名>）

**基本信息**：<性别>，<公历日期 钟表时刻>（<城市>）→ 真太阳时 <时辰> · 农历<干支>年<月日> · <X>局 · 现行<大限宫>大限（虚岁 <N>）

**总评**：<2–3 句直断：主星底色 + 最强格局 + 当前阶段，串成这张盘的"人生形状"。>

### 命宫总论

<主星 + 庙旺利陷 + 三方四正会照，2–4 句定性：性格底色、能力倾向。空宫写借星。>

### 格局定性

<每个已识别格局 1–2 句：格局名 + 分数档 + 是否破格 + 落到本盘的实际含义。
识别为空 → 一句「未成格局，以星情论」带过，不硬凑。>

### 四化着力点

<生年四化用一张小表格（四化 | 星 | 落宫 | 一句解读）；带流年四化时表后接 1–2 句当下引动，流年化忌落宫单独提醒。化禄＝资源所在，化忌＝课题所在。>

### 当前大限

<当前大限宫 + 主星 → 这十年的主题，2–3 句。童限未起运（当前大限为 —）→ 按命宫论并说明。>

### 综论与建议

<3–5 条可执行建议，每条落到具体行为，不复述术语。
其余宫位的信号（四化落点、聚煞、身宫）在这里作为建议依据逐条带出，不设分宫速览章节。>
```

## 形态硬约束

- **篇幅**：全盘解读 800–1500 字。用户单问某宫或用了 `--focus` → 换聚焦形态：基本信息一行 + 该宫星情 + 三方四正 + 结论建议，300–600 字。
- **表格**：全文 ≤ 2 张，只用在四化节；其余内容用短段落与列表。
- **术语**：首次出现配一句白话。每个断语都能指回 CLI 数据（星 / 宫 / 格局名），不凭记忆加星。
- **语气**：直断——先给结论再补依据；破格必说打折。
- **年龄**：一律虚岁，报 CLI 给的数，不换算周岁。
- **口径转达**：CLI 输出里的口径提示（真太阳时校正量、跨午夜改期、晚子时两盘对照、城市歧义候选）出现在基本信息行或紧随其后，**转达完才进入解读**。

## 聚焦形态

用户单问某宫、或你用了 `--focus <宫名>` 时，不要套全盘模板，按聚焦形态给：

1. 基本信息一行（同上，但不展开口径细节）
2. 该宫星情（主星 + 庙旺利陷 + 该宫特有的杂曜煞星）
3. 三方四正会照（该宫的三方四正，以及它们对本宫的影响）
4. 结论与建议（2–3 条）

篇幅 300–600 字。`--focus` 的输出已含对宫详表、三方四正逐宫全星曜、涉及格局、生年/流年四化落宫与运限引动（流年命宫同宫/对冲/会照、小限岁数段、大限十年引动年份）——这些数据直接引用，不要凭记忆补星。宫名口径见 [options.md](options.md)。

### 变体：单问某四化

用户问的是**某个四化**（"贪狼化忌在我盘上什么意思""化禄落哪了"）时，取数用 `--mutagen`（流年 / 流月引动配 `--yearly` / `--monthly`），输出按：

1. 该四化定性（哪颗星化什么、生年四化还是流年四化——生年看先天禀赋，流年看当下引动）
2. 落宫影响（落在哪宫，该宫主管领域（见上表）受到的影响；化禄＝资源所在，化忌＝课题所在）
3. 三方四正波及（落宫的三方四正被会照到的领域；落宫在命 / 财 / 官三方内的点出）
4. 当下引动（生年 × 流年同星引动、当前大限三方是否照到——`--mutagen` / `--decadal` 输出已给）
5. 建议（1–2 条，落到具体行为）

篇幅 200–400 字。⚠️ 这是三合派口径：只论**落宫与会照**，不讲"飞入飞出"，措辞不要带飞星派字眼（体系边界见 SKILL.md「体系硬约束」）。

## 主题形态

用户单问某主题（感情 / 事业 / 财运 / 健康 / 性格……十三主题之一）、或你用了 `--topic <key>` 取数时，按主题形态给：

1. 主题定性（一句话：主宫主星 + 庙旺利陷给这个主题定的调子；空宫写借对宫主星论）
2. 主宫星情（主宫的论断展开，生年四化落主宫的单独点出）
3. 三方四正联动（主宫的三合两宫与对宫对该主题的影响，如感情主题看福德与迁移的牵动）
4. 运限视角（当前大限对该主题的走向；用了 `--view daxian/liunian/liuyue` 时按该视角组织）
5. 实际建议（2–3 条，落到该主题可执行的事）

篇幅 500–900 字。`--topic` 的输出已含命盘关键定制、星曜深层特质、命盘推演、三方四正逐宫、本命四化会照、当前大限与综合建议——这些数据直接引用，不要凭记忆补星。十三主题与主宫的对照（感情→夫妻宫、财运→财帛宫、人际→交友宫……）用 `--topic` 裸开关列出的清单；主宫主管领域见上方白话对照表。知识来源分级提示（verified / traditional / …）随 CLI 输出一并转达，引用「倪师说」的断语要注明口径。

## 流年解读形态

用户问的是**某一年**的运势（"今年如何""2026 年事业"）、或你用了 `--yearly [年]` 取数时，按流年形态给：

1. 流年命宫与主星（流年命宫落本盘哪座宫、坐什么星）
2. 流年四化落点（重点标 ★ 入三方的化，化忌落宫单独提醒）
3. 与大限的关系（流年命宫/三方对照当前大限的宫位，说明引动还是助势）
4. 同星引动（生年 × 流年同星，`--mutagen` 输出已给，直接引用）
5. 建议（2–3 条，落到当年可执行的事）

篇幅基线 300–600 字。`--yearly` 的输出已含流年命宫详表、流年三方四正会照、四化落点（★入三方）与大限三方对照——这些数据直接引用，不要凭记忆补星。

## 合盘形态

用户要的是**两个人**的合盘（`synastry` 请求）时，按合盘形态给：

1. 口径提示转达（任一方晚子时两盘对照提醒出现在最前，转达完才进入解读）
2. 双宫联参表（两方命宫 / 夫妻宫 / 福德宫主星对照）
3. 主星对应判定（引用 CLI 的对应关系判定行：天作之合 / 次级良配 / 无对应）
4. 四化互参（用输出的【双盘四化互参】节：甲方四化落乙方何宫、乙方落甲方何宫）
5. 夫妻宫断语要点（每方主星断语取一句核心，吉凶并陈；空宫写借对宫主星论）
6. 星级定档（按 [synastry-guide.md](synastry-guide.md) 的五档评分标准定档，**注明这是你的裁量结论**——CLI 不输出分数）
7. 建议（2–4 条，落到两人相处的具体行为）

篇幅基线 500–900 字。合盘的方法论与评分标准全文见 [synastry-guide.md](synastry-guide.md)。
