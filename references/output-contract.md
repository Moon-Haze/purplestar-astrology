# 解读输出契约

交付给用户的解读文本按此模板组织——**章节、顺序、命名固定**，`<>` 为待填槽位。
本文件是 `SKILL.md` 指向的细则；`SKILL.md` 只留五节标题、形态清单与三条最要紧的硬约束。全盘五节之外的四种形态（聚焦 / 主题 / 流年 / 合盘）与十二宫主管领域白话对照都在本文件。

## 模板

```markdown
## 命盘解读 · <命宫主星>（<分数最高的格局名>）

**基本信息**：<性别>，<公历日期 钟表时刻>（<城市>）→ 真太阳时 <时辰> · 农历<干支>年<月日> · <X>局 · 现行<大限宫>大限（虚岁 <N>）

**总评**：<2–3 句直断：主星底色 + 最强格局 + 当前阶段，串成这张盘的"人生形状"。>

### 命宫总论

<主星 + 庙旺利陷 + 三方四正会照，2–4 句定性：性格底色、能力倾向。空宫写借星。>

### 格局定性

<每个已识别格局 1–2 句：格局名 + 分数档 + 是否破格 + 落到本盘的实际含义。
识别为空 → 一句「未成格局，以星情论」带过，不硬凑。>

### 四化着力点

<生年四化用一张小表格（四化 | 星 | 落宫 | 一句解读）；带流年四化时表后接 1–2 句当下引动，流年化忌落宫单独提醒。化禄＝资源所在，化忌＝课题所在。`--mutagen` 输出还含**当前大限宫干四化**（文墨排盘口径）与（给了 `--monthly` / `--daily` / `--hourly` 时的）流月 / 流日 / 流时层——引用时同按「落宫与会照」组织，流时层只在用户问到具体时辰才展开。>

### 当前大限

<当前大限宫 + 主星 → 这十年的主题，2–3 句。童限未起运（当前大限为 —）→ 按命宫论并说明。>

### 综论与建议

<3–5 条可执行建议，每条落到具体行为，不复述术语。
其余宫位的信号（四化落点、聚煞、身宫）在这里作为建议依据逐条带出，不设分宫速览章节。>
```

## 形态硬约束

- **篇幅**：全盘解读 800–1500 字。用户单问某宫或用了 `--focus` → 换聚焦形态：基本信息一行 + 该宫星情 + 三方四正 + 结论建议，300–600 字。
- **表格**：全文 ≤ 2 张，只用在四化节；其余内容用短段落与列表。
- **术语**：首次出现配一句白话。每个断语都能指回 CLI 数据（星 / 宫 / 格局名），不凭记忆加星。
- **语气**：直断——先给结论再补依据；破格必说打折。
- **年龄**：一律虚岁，报 CLI 给的数，不换算周岁。
- **口径转达**：CLI 输出里的口径提示（真太阳时校正量、跨午夜改期、晚子时两盘对照、城市歧义候选）出现在基本信息行或紧随其后，**转达完才进入解读**。

## 边界声明（每种形态都要带，不得省略）

本技能输出的是**传统命理体系内部的静态论断**，交付时必须让读者看清它是什么、不是什么。
四种形态（全盘 / 聚焦 / 主题 / 流年 / 合盘）**一律**在结尾附上对应的一条短句，不要只在报告形态里写：

| 形态 | 结尾必带 |
| --- | --- |
| 全盘 / 聚焦 / 流年 | 本解读为传统命理体系内的静态论断，不是医疗、法律或投资意见。 |
| 主题 = health | 本节谈的是传统命理对体质与易感倾向的描述，不是医学诊断；有具体症状请就医。 |
| 主题 = wealth | 本节不涉及具体投资标的与收益预测，仅为传统命理对财务模式的描述。 |
| 主题 = 其他 / 全盘含财运节 | 涉及财务处为传统命理描述，不构成投资建议。 |
| 合盘 | 星级为依传统标准的裁量结论，不是对两人关系的判定。 |

三条硬约束：

1. **health 形态不给诊断**。只写「体质偏寒 / 脾胃为薄弱环节」这类体系内描述，**不写**「你可能有某某病」，也不给治疗方案；用户描述了具体症状、用药或检查结果时，**明确转「这需要医生判断，命理不能替代」**。
2. **wealth 形态不给标的**。可写财源类型、聚散节奏、四化落财帛宫的含义；**不写**具体股票/基金/房产买卖时点与收益预测。
3. **合盘的星级必须自标裁量**。「星级定档」是模型依 `synastry-guide.md` 五档标准做的判断，**不是命令输出的客观分**，同句注明这一点。

## 聚焦形态

用户单问某宫、或你用了 `--focus <宫名>` 时，不要套全盘模板，按聚焦形态给：

1. 基本信息一行（同上，但不展开口径细节）
2. 该宫星情（主星 + 庙旺利陷 + 该宫特有的杂曜煞星）
3. 三方四正会照（该宫的三方四正，以及它们对本宫的影响）
4. 结论与建议（2–3 条）

篇幅 300–600 字。`--focus` 的输出已含对宫详表、三方四正逐宫全星曜、涉及格局、生年/流年四化落宫与运限引动（流年命宫同宫/对冲/会照、小限岁数段、大限十年引动年份）——这些数据直接引用，不要凭记忆补星。宫名口径见 [options.md](options.md)。

### 变体：单问某四化

用户问的是**某个四化**（"贪狼化忌在我盘上什么意思""化禄落哪了"）时，取数用 `--mutagen`（流年 / 流月引动配 `--yearly` / `--monthly`），输出按：

1. 该四化定性（哪颗星化什么、生年四化还是流年四化——生年看先天禀赋，流年看当下引动）
2. 落宫影响（落在哪宫，该宫主管领域（见上表）受到的影响；化禄＝资源所在，化忌＝课题所在）
3. 三方四正波及（落宫的三方四正被会照到的领域；落宫在命 / 财 / 官三方内的点出）
4. 当下引动（生年 × 流年同星引动、当前大限三方是否照到——`--mutagen` / `--decadal` 输出已给）
5. 建议（1–2 条，落到具体行为）

篇幅 200–400 字。⚠️ 这是三合派口径：只论**落宫与会照**，不讲"飞入飞出"，措辞不要带飞星派字眼（体系边界见 SKILL.md「体系硬约束」）。

## 主题形态

用户单问某主题（感情 / 事业 / 财运 / 健康 / 性格……十三主题之一）、或你用了 `--topic <key>` 取数时，按主题形态给。骨架五步，分节标题按下方分主题表取用（承自上游解读面板的专题模板，后七主题按同一骨架补齐）：

1. 主题定性（一句话：主宫主星 + 庙旺利陷给这个主题定的调子；空宫写借对宫主星论）
2. 主宫星情（主宫的论断展开，生年四化落主宫的单独点出）
3. 三方四正联动（主宫的三合两宫与对宫对该主题的影响，如感情主题看福德与迁移的牵动）
4. 运限视角（当前大限对该主题的走向；用了 `--view daxian/liunian/liuyue` 时按该视角组织）
5. 实际建议（2–3 条，落到该主题可执行的事）

| key         | 主题       | 分节（依序）                                                 |
| ----------- | ---------- | ------------------------------------------------------------ |
| overview    | 命格总览   | 命格定性／主星解读／三方四正／当前大限／优势与注意           |
| personality | 性格特质   | 命宫主星性格／三方性格综合／人际关系模式／优势与人生课题     |
| love        | 感情婚姻   | 感情格局／夫妻宫分析／三方联动／当前大限感情运／实际建议     |
| career      | 事业职业   | 事业格局／官禄宫分析／财帛宫联动／当前大限事业运／实际建议   |
| wealth      | 财富运势   | 财运格局／财帛宫分析／田宅宫（财库）／当前大限财运／理财建议 |
| health      | 健康状况   | 疾厄宫主星／主要风险／大限健康走势／预防建议                 |
| family      | 兄弟合伙   | 兄弟格局／兄弟宫分析／合伙与同事关系／当前大限／建议         |
| children    | 子女缘分   | 子女缘格局／子女宫分析／下属晚辈关系／当前大限／建议         |
| move        | 迁移外出   | 迁移格局／迁移宫分析／外出机遇与变动／当前大限迁移运／建议   |
| friends     | 人际贵人   | 人际格局／交友宫分析／贵人与小人／当前大限人际运／建议       |
| home        | 田宅不动产 | 田宅格局／田宅宫分析／不动产与财库／当前大限田宅运／建议     |
| spirit      | 精神福德   | 精神格局／福德宫分析／内心福分与消耗／当前大限福德运／建议   |
| parents     | 父母长辈   | 父母缘格局／父母宫分析／长辈缘与文书契约／当前大限／建议     |

分节表的三条使用规则：

- **分节与骨架一一对应**：「格局／定性」类节＝骨架 1，「宫分析」类节＝骨架 2，「联动／综合」类节＝骨架 3，「大限」类节＝骨架 4，「建议／注意」类节＝骨架 5。personality 没有大限节——性格是本命话题，四节给全即可，不硬凑运限。
- **特化节的展开口径**：career 的「财帛宫联动」＝官禄宫三方里的财帛宫（官禄三合·财帛，`--topic career` 输出已列）；wealth 的「田宅宫（财库）」是**财库联参**，田宅不在财帛三方四正内，单独一节点出积蓄与不动产，星情取自 `--focus 田宅` 或 `--topic home`，不要并进三方联动混写。
- **标题直出**：分节标题照表用（可去掉「／」分隔写成小节标题），不自创同义标题。

篇幅 500–900 字。`--topic` 的输出已含命盘关键定制、星曜深层特质、命盘推演、三方四正逐宫、本命四化会照、当前大限与综合建议——这些数据直接引用，不要凭记忆补星。十三主题与主宫的对照（感情→夫妻宫、财运→财帛宫、人际→交友宫……）用 `--topic` 裸开关列出的清单；主宫主管领域见上方白话对照表。知识来源分级提示（verified / traditional / …）随 CLI 输出一并转达，引用「倪师说」的断语要注明口径。

## 全盘报告形态（--report）

用户要**一份完整交付物**（"给我一份全面的分析报告""十三项都讲一遍"）、或你用了 `--report` 取数时，CLI 直接产出 Markdown 文档，你**原样转发给用户**（可按需摘录），不要改写成终端对话体。报告结构与板块顺序由 CLI 固定：

- **文档头**：出生信息 / 农历 / 命宫身宫五行局 / 生年四化落宫 / 已入格局 / 当前虚岁与大限，六行清单；有口径提示（出生地解析 / 晚子时）时以引用块紧跟其后——**转达口径的义务**在这里同样成立。
- **13 个板块**（`##` 二级标题，每节带主宫·主星徽标）：命格总览 / 财富运势 / 事业职业 / 感情婚姻 / 性格特质 / 健康状况 / 兄弟合伙 / 子女缘分 / 迁移外出 / 人际贵人 / 田宅不动产 / 精神福德 / 父母长辈。**财运在事业前、性格在感情后**是产品口径，与 `TOPIC_KEYS` 存储序不同，不要"纠正"它。
- **每节小节流**（有素材才出，辅助宫主题无总览素材时直接从核心论断起）：定调（主星一句简述）→ 总览 → 核心论断 → 命盘推演 → 三方四正联动 → 四化路径分析（含魁钺贵人）→ 当前大限 → 主题专属补充（health 的健康取象 / personality 的性格深描）→ 命盘依据（事实层清单）→ 经典出处（古籍库检索引文，查不到即省略）→ 综合建议。
- **尾注**：知识来源分级 + 虚岁口径 + 「本报告为本命盘静态论断」三行——动态论断（大限 / 流年 / 流月视角）不在报告里，要用 `--topic <key> --view daxian|liunian|liuyue` 单独取。

三条使用规则：

- **本命静态口径**：`--report` 不接受 `--view` 与运限参数（同给报错指路）；用户在报告基础上追问运限，按主题形态 / 流年形态另答，不要混进报告。
- **经典出处是事实层**：引文逐字出自本仓古籍库（《骨髓赋》《紫微斗数全集》《紫微斗数全书》），转发时不要改写、拼接或"顺一下古文"。
- **篇幅不限 800–1500**：全盘报告形态的篇幅基线是 13 节 × 每节数百字，**不适用**「全盘解读 800–1500 字」约束——那条约束管的是终端对话体；报告是交付物，完整性优先。

## 流年解读形态

用户问的是**某一年**的运势（"今年如何""2026 年事业"）、或你用了 `--yearly [年]` 取数时，按流年形态给：

1. 流年命宫与主星（流年命宫落本盘哪座宫、坐什么星）
2. 流年四化落点（重点标 ★ 入三方的化，化忌落宫单独提醒）
3. 与大限的关系（流年命宫/三方对照当前大限的宫位，说明引动还是助势）
4. 同星引动（生年 × 流年同星，`--mutagen` 输出已给，直接引用）
5. 建议（2–3 条，落到当年可执行的事）

篇幅基线 300–600 字。`--yearly` 的输出已含流年命宫详表、流年三方四正会照、四化落点（★入三方）与大限三方对照——这些数据直接引用，不要凭记忆补星。

## 合盘形态

用户要的是**两个人**的合盘（`synastry` 请求）时，按合盘形态给：

1. 口径提示转达（任一方晚子时两盘对照提醒出现在最前，转达完才进入解读）
2. 双宫联参表（两方命宫 / 夫妻宫 / 福德宫主星对照）
3. 主星对应判定（引用 CLI 的对应关系判定行：天作之合 / 次级良配 / 无对应）
4. 四化互参（用输出的【双盘四化互参】节：甲方四化落乙方何宫、乙方落甲方何宫）
5. 夫妻宫断语要点（每方主星断语取一句核心，吉凶并陈；空宫写借对宫主星论）
6. 星级定档（按 [synastry-guide.md](synastry-guide.md) 的五档评分标准定档，**注明这是你的裁量结论**——CLI 不输出分数）
7. 建议（2–4 条，落到两人相处的具体行为）

篇幅基线 500–900 字。合盘的方法论与评分标准全文见 [synastry-guide.md](synastry-guide.md)。
