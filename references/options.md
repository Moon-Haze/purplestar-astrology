# 参数面细则

`SKILL.md` 只列高频参数；本文件是完整参数面，以及两个**不会报错、但会静默给出错误结果**的陷阱。

## 出生信息参数

`--date` / `--lunar`（+`--leap`）；`--time` 或 `--branch 0-12`、`--late-zi`、`--eot`；`--gender`（**必填**）；`--lng` / `--city` / `--province`；`--name`。

⚠️ `--late-zi` 须配合 `--time`；直接指定时辰的晚子时用 `--branch 12`，两者不可同给（`--late-zi` 缺 `--time` 即报错）。

⚠️ `--year` / `--month` / `--day` 三连**已删**（2026-09-30）：`--date 1990-5-15` 完全覆盖（格式宽松、月日不补零）。误敲 `--year` 会被拼错建议引向 `--yearly`（编辑距离 2）。

## 位置参数快捷形态（astrology 专用）

`astrology 1990-5-15 9:30 男 北京` —— 按形态归类、顺序无关：

- 日期 `^\d{4}-\d{1,2}-\d{1,2}$`、时刻 `^\d{1,2}:\d{2}$`、性别 `男|女|male|female|m|f`，其余**中文 token** 为城市名；
- **省市连写**（`山东青岛` / `内蒙古鄂尔多斯`）由容错解析剥前缀；**裸省名**（`山东`）按省会计；省+市**带空格**（`山东 青岛` 两个 token）报错并提示连写；
- 同类 token 出现两个（两个日期 / 两个城市）报错；**参数优先**——位置参数只填空，旗标已给的项不被覆盖；
- 农历生日只能走 `--lunar`（与公历同形，无法按形态区分）；`classics` / `stars` 的位置参数仍是检索词。

## 拼音别名（显式映射，非拼错容错）

`--geju→--pattern`、`--sihua→--mutagen`、`--liunian→--yearly`、`--liuyue→--monthly`、`--daxian→--decadal`、`--xiaoxian→--ages`。别名被解析层归一到英文主名（help / 文档一律用主名）；`--patern` 仍报错并建议 `--pattern`。

## astrology 功能参数（专题可叠加，独占分支除外）

默认（不带任何功能参数）出**概览**：命盘总览三行 + 基本信息 12 行面板（无条件）+ 口径提示 + 运限速览 + 功能参数指路。**专题参数**（pattern / mutagen / yearly / monthly / decadal / ages / focus）可叠加，给了哪个就**追加**该专题的详版；`--info` / `--palaces` / `--topic` 是**独占分支**（给出即接管输出，静默组合会报错指路）。优先级：`--palaces` > `--topic` > 其他功能参数。`--view` 仅在 `--topic` 路径下被读取，单独或与其他参数组合无效。

| 参数                | 形态         | 内容                                                                                                          |
| ------------------- | ------------ | ------------------------------------------------------------------------------------------------------------- |
| `--info`            | 开关         | **只输出**基本信息面板这一节：性别 / 经度 / 钟表与真太阳时 / 农历 / **节气与非节气四柱** / 五行局 / 命盘类型 / 命主·身主·斗君·身宫。四柱仅为出生时刻记录，**不做八字论命** |
| `--pattern`         | 开关         | 格局识别（判词 + 成立/加分/破格 + 出处）                                                                      |
| `--mutagen`         | 开关         | 生年 / 流年（/ 流月）四化落宫 + 生年×流年**同星引动**                                                          |
| `--yearly [年]`     | 值可选       | 流年专题：流年命宫（**年支所在宫**，三合派不重排）+ 三方四正会照 + 四化落点（★ = 入流年三方）+ 与当前大限三方的对照。裸开关 = 当前年 |
| `--monthly <农历月>` | 值必填      | 配合 `--mutagen` 四化专题（**强制**）：追加该农历月的流月四化（流年缺省取当年，可用 `--yearly` 指定；月干由流年干五虎遁推）；`--topic` 路径下作为流月视角的月份被主题自己消费 |
| `--decadal [虚岁]`  | 值可选       | 十年大运：大运时间轴（每步附主星）+ 指定限三方四正与生年四化落点 + **限内十年逐年对照**（流年命宫 + 小限）。裸开关 = 当前虚岁 |
| `--ages [虚岁]`     | 值可选       | 小限专题：小限宫 + 三方四正 + 十二宫岁数分布（虚岁 1–120）+ 与流年命宫同宫/对宫关系。裸开关 = 当前虚岁          |
| `--focus <宫名>`    | 值必填       | 宫盘分析（**四项深化**，2026-09-30 起）：三方四正逐宫全星曜 + 对宫完整详表 + 涉及此宫的格局全列 + 小限岁数段与大限十年内流年引动年份 + 命主/身主星标注与身宫标记 |
| `--palaces`         | 开关         | 十二宫逐宫详表（原 `chart` 命令职责；`--palaces --json` 顶层即命盘本身）                                       |
| `--topic <key>`     | 值可选       | 主题论断（原 `topic` 命令职责，13 主题动态推算 + 知识来源分级披露）；配 `--view mingpan/daxian/liunian/liuyue` 换视角。裸开关 = 列主题清单 |

`--decadal` / `--ages` 的值域是 **1–120 虚岁**，越界报错（不静默兜底）。

## `--config` / `--template`（配置文件输入）

- `--config <my.json>`：键名与参数的 camelCase 主名同名（`date` / `time` / `city` / `gender` / `pattern` / `yearly` …），出生信息与功能参数都可写；**命令行同名参数覆盖配置**（配置是基底）；`_` 前缀键是注释，跳过；未知键 / 非法值与命令行同规则中文报错。
- `--template`：打印可直接使用的模板 JSON 到 stdout（`--template > my.json` 落盘后可直接 `--config my.json`；模板含虚构示例与 `_说明` 注释键）。

## `--charts`（synastry 专用）

`synastry --charts /tmp/a.json,/tmp/b.json` —— 逗号分隔**恰好两份** `astrology --json` 的产物（甲先乙后；两路径相同 = 自盘对照，允许）。份数不对 / 文件不可读 / JSON 不符消费契约均报具体原因。`--a-chart` / `--b-chart` 与整个 `a-` / `b-` 前缀已退役（未知参数）。

## `--focus` 的宫名口径

用本项目口径（倪师《天纪》），十二宫统一带「宫」字：

> 命宫、兄弟宫、夫妻宫、子女宫、财帛宫、疾厄宫、迁移宫、**交友宫**、官禄宫、田宅宫、福德宫、父母宫。

第 8 宫是「**交友宫**」（排盘引擎 iztro 内部叫「仆役」，那是上游口径，**不要照抄**）。

`--focus` 会对输入先做一次归一化，下列写法都命中同一宫，可任选：

- **全名**（`--focus 交友宫`）
- **去「宫」字的简称**（`--focus 交友`）
- **iztro 旧写法**（`--focus 仆役` / `--focus 仆役宫`）

另外也接受**地支名**（`--focus 巳`）—— 注意它匹配的是「地支为该字的那一宫」，**不一定是命宫**。

都匹配不上才会报错，报错信息里会列出该盘实际的十二宫名。

## 解析引擎的两个契约

- **重复参数报错**：同一参数（含主名与别名同现，如 `--geju --pattern`）给两次即报错——旧引擎「取末值」已废止。
- **贪婪取值**：取值参数**无条件吃紧随 token**（`--limit -3` 的 `-3` 是值不是短参数）。⚠️ 此行为 Node 版本敏感（需 ≥ 22.18），selftest 有断言钉死。

## 完整帮助

```bash
node scripts/purple-star.ts help            # 总览（man 八节结构）
node scripts/purple-star.ts astrology --help # 每命令（man 七节 + 归属参数子集）
```

`help` 的参数段由 `scripts/cli/args.ts` 的 `OPTION_GROUPS` 派生，与解析器同源——**它列出的就是本 CLI 的全部合法参数**，本文件不重复维护一份清单；每命令 `--help` 的参数子集由命令 → 参数归属表（`scripts/cli/help.ts` 的 `OPTION_OWNERSHIP`）过滤，是 help 视图而非硬校验（作用域仍是 skill 级）。
