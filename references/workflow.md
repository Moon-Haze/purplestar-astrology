# 工作流详展开

本文件是 `SKILL.md`「工作流」一节的展开——**排盘取数、按需查知识源、逐步解读**的完整说明。
`SKILL.md` 里只有三步各一句，读到这里说明你要真的开工了。

## 第 1 步：排盘取数

```bash
# 位置参数快捷形态（按形态归类，顺序无关；示例数据为虚构）
node scripts/purple-star.ts astrology 2011-06-24 07:45 男 杭州
# 完整参数形态（两种形态可混用，参数优先）
node scripts/purple-star.ts astrology \
  --date 2011-06-24 --time 07:45 --city 杭州 --gender male
```

在仓库根目录执行（脚本也能从任意 cwd 运行）。`astrology`（2026-09-30 四命令合一：原 analyze / chart / topic 融入参数）默认输出**概览**：

- 命盘总览三行（基本信息 / 农历 / 命宫身宫紫微 / 命宫三方四正）
- **基本信息 12 行面板**（无条件输出：钟表/真太阳时、农历、节气与非节气四柱、五行局、命主身主、斗君、身宫）
- 口径提示（出生地解析 / 晚子时对照）
- **运限速览**：当前虚岁 · 大限 · 流年命宫 · 小限宫 —— 四个运限坐标一次定位
- 功能参数指路一行

深入内容全靠**功能参数**（可叠加，按 `--info → --pattern → --mutagen → --yearly → --decadal → --ages → --focus` 顺序输出）：

| 参数                 | 给你什么                                                                       |
| -------------------- | ------------------------------------------------------------------------------ |
| `--info`             | **只输出**基本信息面板这一节                                                    |
| `--pattern`          | 格局识别（含古籍出处与成立/加分/破格三层条件）                                 |
| `--mutagen`          | 生年 / 流年（/ `--monthly` 流月）四化落宫 + 生年×流年同星引动                  |
| `--yearly [年]`      | 流年专题：流年命宫详表、流年三方四正会照、四化落点（★入三方）、与大限三方的对照 |
| `--decadal [虚岁]`   | 十年大运：大运时间轴、指定限三方四正、生年四化落点、**限内十年逐年对照表**（流年命宫 + 小限） |
| `--ages [虚岁]`      | 小限专题：小限宫详表、三方四正、十二宫岁数分布、与流年命宫的同宫/对宫关系      |
| `--focus <宫名>`     | 宫盘四项深化：三方四正逐宫全星曜、对宫完整详表、涉及格局全列、小限岁数段 + 大限十年引动年份 + 命主/身主/身宫标记 |
| `--palaces`          | 十二宫逐宫详表（原 `chart` 命令职责）                                          |
| `--topic <key>`      | 主题论断（原 `topic` 命令职责，配 `--view` 换视角）                            |

`--decadal` / `--ages` 不带值 = 当前虚岁；`--yearly` 不带值 = 当前年。拼音别名（`--geju` 等）仍被识别。
**全盘解读通常 `astrology --pattern --mutagen --decadal` 一次拿齐**；结构化数据用 `--json`；批量排盘用 `--config <my.json>`（`--template` 生成模板）。

### 只给农历时

```bash
# 农历 1987 年十月廿三（闰月加 --leap；示例数据为虚构）
node scripts/purple-star.ts astrology \
  --lunar 1987-10-23 --time 10:30 --city 杭州 --gender male
```

### 只知时辰名时

```bash
node scripts/purple-star.ts astrology \
  --date 2011-06-24 --branch 5 --gender male --lng 116.4
```

`--time` 与 `--branch` **二选一**；`--branch` 取 0-11（0=子 … 11=亥）或 12（晚子时）。

### 城市名容错

`杭州` / `杭州市` / `浙江省杭州市` 都能解析；**做了容错解析或存在同名歧义时，脚本会在【出生地解析】里说明**，看到就要留意（歧义会提示候选，让用户确认或改用 `--lng`）。

## 第 2 步：按需深入知识源

CLI 已给出命盘数据与格局结论。需要展开论证时，**直接读这些文件**（它们是本技能的权威依据，不要凭记忆编造）：

| 需要什么                                                                                         | 读哪里                                                                                                                                              |
| ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 格局判定规则全文（80+ 格局的必须/加分/破格三层条件）+ 各格局的短判词与主题长判词 | `scripts/ziwei/patterns/`（basic / superior / medium / converged / enhancing / malefic 各判定 + `data.ts` 的 `PATTERN_VERDICTS` 判词表）                                                  |

| **某主题（感情/事业/财运…）的整段论断**                                                          | `topic` 命令（动态推算：主宫主星 + 三方四正 + 四化会照 + 大限流年）；数据在 `scripts/ziwei/analysis/`（`data.ts` 论断文案 + 其余为动态推算） |

## 第 3 步：解读

按这个顺序展开，不要跳步（`references/output-contract.md` 的五节与这五步一一对应）：

1. **命宫定基调** —— 命宫主星 + 庙旺利陷 + 三方四正会照。空宫则借对宫主星论（数据里已给 `borrowedStars`）。
2. **格局定性** —— CLI 已列出识别到的格局及其成立/加分/破格条件。破格条件被触发的，必须说明「格局打折」而非直接断吉。
3. **四化定着力点** —— 生年四化看先天禀赋所在；流年四化看当下引动。**化忌落宫是问题所在宫**，化禄落宫是资源所在宫。
4. **大限看阶段** —— 当前大限宫位 + 该宫星曜，判断这十年的主题。
5. **结论落到具体建议** —— 不要停在术语堆砌。

输出文本的章节、顺序、命名、篇幅与语气，见 [output-contract.md](output-contract.md)。
