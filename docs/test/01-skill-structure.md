## 三、发现的问题

### 🔴 P1：性别无护栏，静默按男性排盘

本次测试**最严重的发现**。

```bash
# 不给 --gender
$ node scripts/purple-star.mjs analyze --date 1990-05-15 --time 09:30 --city 北京
【命盘总览】 ... · 男 · 经度 116.4°E     ← 静默默认男性，exit=0，无任何提示
```

实测男女两盘 **diff 56 行**，大限顺逆完全相反：

```text
不给性别（默认男）              给 --gender female
福德 │ 寅 │ 26-35岁       ↔     福德 │ 寅 │ 106-115岁
田宅 │ 卯 │ 36-45岁 ←当前  ↔     田宅 │ 卯 │ 96-105岁
```

**矛盾点**：SKILL.md 第 30 行称性别「**必问**」，第 24 行称「用户没给全时**必须追问**，不要猜」——但 CLI **既不强制也不警告**。一旦模型漏问，用户拿到的是一张**没有任何异常信号的错盘**，且大限全反。这比报错危险得多。

**实情比初报更严重**（修复前核实）：

```js
// scripts/purple-star.mjs:357-358（修复前）
const genderRaw = String(g("gender") ?? "male").toLowerCase();
const gender = ["female", "f", "女"].includes(genderRaw) ? "female" : "male";
```

不只是**缺失**时默认男性——**任何非法值也静默落到 `male`**（`--gender xyz` → 男）。写错了不报错，直接给一张错盘。

## 四、误报撤回

报告初稿列了 P1–P7，其中**两条是我自己的误报**，核实后撤回：

| 初报 | 实情 |
| --- | --- |
| **P6** `--focus 不存在的宫` 静默忽略 | ❌ **有完整报错**：`【聚焦失败】找不到宫位「不存在的宫」。可用：福德、田宅、官禄、仆役、迁移、疾厄、财帛、子女、夫妻、兄弟、命宫、父母`（`purple-star.mjs:870`）。先前 grep 的 `【聚焦` 恰好命中了 `【聚焦失败】` 却当成 0 处理。仅 `exit=0` 一项可议，但"成功输出 + 一条警告"对分析类命令是合理的 |
| **P7** `stars` 输出缺尾部换行 | ❌ 末尾**有换行**（`od -c` 实证 `\n`），管道 `wc -l` = 1。先前的 0 是 `$(...)` 命令替换剥离尾部换行造成的假象 |

**教训**：`grep` 模式要能区分「命中」与「命中反面」，`$(...)` 会剥离尾部换行——两处都是**测量方法**出的错，不是被测对象的问题。
