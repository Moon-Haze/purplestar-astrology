## 一、做得好的地方

### 参数易用性
1. **英文主名 + 拼音别名双识别**：`--pattern`（主）/ `--geju`（别名），既规范又照顾中文输入习惯。
2. **位置参数快捷形态**：`astrology 1990-05-15 9:30 男 北京`，按形态归类、顺序无关，可与参数混用（参数优先）。
3. **错误提示质量极高**：中文、说清原因、给可操作建议：
   - 拼错：`--patern` →「最接近的是 --pattern」
   - 非法值：`--gender x` →「应为 male 或 female」
   - `--topic xxx`：直接列出全部 13 个合法 key
   - 未知命令：列出全部可用命令
4. **缺必填不猜**："缺一问一"，且说明为何必填（如"性别决定大限顺逆，缺失会排出错盘"）。
5. **裸开关设计**：`--topic` 不带值 = 列清单，`--decadal` 裸写 = 当前虚岁，降低记忆负担。
6. **帮助完整**：man 结构（NAME/SYNOPSIS/DESCRIPTION/OPTIONS/EXAMPLES/NOTES/SEE ALSO），每命令还有专属 `--help`。

### 输出合理性
1. 默认概览信息密度合适：总览三行 + 基本信息面板 + 运限速览 + 指路。
2. 标题层级清晰：`【】` 分节、`────` 分隔、缩进对齐。
3. `--json` 结构干净，字段对齐 iztro（`soulBranch`/`fiveElementsClass`），适合程序消费。
4. 专题可叠加：`--pattern --mutagen` 同出格局 + 四化。
5. 主动标注口径：真太阳时校正量、"示例数据为虚构"。
