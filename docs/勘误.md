# 勘误

> 《天纪》讲稿语料（`scripts/corpus/data/tianji.ts`）在清洗时给三处原话加了勘误注记，
> 注记均指向本文件。勘误依据为《紫微斗数全书》原文（卷次见各条），整理于此供检索。
> 引用任何一条时以语料内的逐字注记为准，本文件是汇总视图。

## 1. 太阳化忌的年份前提（讲稿 00:36:09 处）

原话「文昌化忌与太阳同宫、十年化忌」的推演有年份前提：按正确排盘，
**太阳化忌只在 1994 甲戌年**（太阳庚干化忌，见生年四化表）。离开该年份
谈「太阳化忌」不成立。

## 2. 天同的斗分（讲稿 00:42:32 处）

倪师把紫微一组的星都称**北斗星系**，与《全书》有出入：

- 卷一：「天同**南斗**益算保生之星」
- 卷二：「天同属水金**南斗**」

即**天同属南斗，不属北斗**。

## 3. 七杀 / 破军 / 贪狼的斗分（讲稿 00:00:07 处）

倪师把天府一组的星都称**南斗星系**，与《全书》有出入——这三颗里**只有七杀属南斗**：

- 卷一：「七杀**南斗**第六星也」
- 「破军属水，**北斗**第七星也」
- 「贪狼**北斗**解厄之神，第一星也」

即破军、贪狼都属北斗。
