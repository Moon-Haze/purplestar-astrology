## 看着像 bug，其实不是

- **真太阳时跨过午夜，出生日期被顺延 / 回退一天**：只换时辰不换日期，「日 + 时」指向的
  就不是出生时刻（喀什 00:30 的真太阳时是前一日 21:34，农历日会错一天）。输出里会写明
  「已跨过午夜」，这是正确行为。
- **1986–1991 年的钟表时间被自动减了 1 小时**：中国夏令时区间自动回拨。出生证明上的
  时间已经自行减过的，加 `--no-dst` 关掉回拨。
- **【出生地解析】提示行**：城市名做过容错解析（`杭州市` / `浙江省杭州市` 都能认）或存在
  同名歧义。歧义会列候选——确认后重敲，或直接改用 `--lng` 给经度。
- **缓存**：排盘结果默认按出生信息哈希落在**系统临时目录**（`purplestar-astrology-v<版本>-<用户>`），
  同一农历年内重复排同一人直接读缓存。想强制现排加 `--no-cache`；想清缓存删掉那个临时
  子目录即可，或设 `ZIWEI_CACHE_DIR` 指到持久位置获得跨重启缓存。缓存坏了最多丢速度，
  不会给错盘。

## 已知口径（白话）

- **晚子时**：23:00–23:59 出生时，子时横跨两日，【当日早子时】与【晚子时算次日】排出的是
  **两张不同的盘**。拿不准或要复核，加 `--late-zi`（配合 `--time`）或直接 `--branch 12`
  各排一张对照。
- **虚岁**：运限一律虚岁，以农历正月初一为界，不换算周岁。「尚未起运」（大限索引 -1）是
  正常状态，不是缺数据。
- **真太阳时**：给了 `--city` / `--lng` 就按经度校正；均时差（±16 分）默认**不计**，
  需要时加 `--eot`。
- **三合派口径**：论断框架命宫为本、三方为用；**不做**宫干自化与来因宫。第十二宫叫
  「交友宫」（排盘引擎内部的「仆役」是上游口径，别照抄）；`--focus` 对宫名做归一化，
  全名 / 去「宫」简称 / 地支名都认。
- **四柱只是记录**：输出里的四柱仅作出生时刻留痕，本工具**不做八字论命**。
- **天纪语料授权**：天纪判语等倪海厦相关语料为 CC BY-NC-SA（非商业、署名、相同方式共享），
  引用时注意遵守。
