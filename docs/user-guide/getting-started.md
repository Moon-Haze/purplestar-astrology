# 快速开始：第一张盘

## 装起来

**环境要求：Node ≥ 22.18。** 低于这个版本会在启动时报解析错误——脚本依赖 Node 原生的
TypeScript 类型擦除（`module.registerHooks`），没有构建步骤，也不需要 `tsx` 之类的转译器。
先确认：

```bash
node --version    # 需要 ≥ 22.18
```

然后：

```bash
git clone <本仓库> && cd purplestar-astrology
npm install       # 只装 iztro / lunar-typescript 两个依赖，版本由 lock 文件锁定
```

装完冒烟测试一条（应打印 man 风格的总览帮助）：

```bash
node scripts/purple-star.ts help
```

想确认安装完全正常，可以跑一遍内置自检（排盘 / 古籍 / 合盘三段断言，约几秒）：

```bash
node scripts/purple-star.ts selftest
```

日常使用只需要 `npm install` 一次；脚本从仓库根或任意目录运行都可以（内核定位走脚本
自身所在路径，不依赖 cwd）。

## 第一张盘

排盘四必问：**出生日期、出生时间、性别、出生地**——缺哪问哪，不要让工具猜。

```bash
# 位置参数快捷形态：日期 时刻 性别 城市，按形态归类、顺序无关（示例数据为虚构）
node scripts/purple-star.ts astrology 2011-06-24 07:45 男 杭州
```

等价的完整参数形态（两种可混用，同名参数优先）：

```bash
node scripts/purple-star.ts astrology \
  --date 2011-06-24 --time 07:45 --city 杭州 --gender male
```

不带任何功能参数时，输出**概览**：命盘总览三行 + 基本信息面板 + 运限速览 + 专题指路。
实跑一遍，然后对照下面逐段认读。

## 输出逐段认读

```text
【基本信息】
性别 : 男
公历生日 : 2011-06-24
地理经度 : 120.100
钟表时间 : 07:45
真太阳时 : 钟表 07:45 → 真太阳时校正 +0 分 → 辰时(07:00-09:00)
农历时间 : 辛卯年五月廿三日辰时
四柱(节气与非节气同) : 辛卯 甲午 庚戌 丙子
五行局数 : 木三局
命盘类型 : 三合盘(天盘)
命宫:寅 · 身宫:戌 · 紫微落:申
三方四正:命宫/官禄宫/财帛宫/迁移宫
身主:天同; 命主:禄存; 子年斗君:子
（注：四柱仅为出生时刻记录，本技能不做八字论命。）
```

| 行                 | 什么意思                                                                   |
| ------------------ | -------------------------------------------------------------------------- |
| 地理经度           | 排盘实际用的经度。给了 `--city` 就用该城市的；`--lng` 直接用你给的数         |
| 钟表时间 / 真太阳时 | 出生证明上的钟表时间，与经度校正后的真太阳时。**排盘以真太阳时所落时辰为准** |
| 农历时间           | 公历自动换算成的农历（含干支年与时辰）                                     |
| 四柱               | 仅作出生时刻记录，**本工具不做八字论命**                                   |
| 五行局数           | 命宫的五行局（如「木三局」），决定起运与部分格局判定                       |
| 命宫 / 身宫 / 紫微落 | 三个坐标：命宫地支、身宫地支、紫微星所落宫位                             |
| 三方四正           | 命宫 + 命宫三合方两宫 + 对宫，三合派论断的基本坐标系                      |
| 身主 / 命主 / 斗君 | 三颗定位星与子年斗君（流月推算的起点）                                    |

```text
【运限速览】虚岁 16 · 大限 13-22岁 兄弟宫(丑) · 流年 2026 丙午 流年命宫午·官禄宫 · 小限辰·福德宫
【专题深入】--pattern 格局 · --mutagen 四化 · --decadal [虚岁] 大限 · --ages [虚岁] 小限 · --yearly [年] 流年 · --focus <宫> 宫盘深化 · --palaces 十二宫详表 · --topic <key> 主题论断 · --report 全盘报告(Markdown)
```

- **运限速览**一行给四个运限坐标：当前**虚岁**（以农历春节为界，不是周岁）、当前大限
  （岁数区间 + 宫位）、流年命宫、小限宫——定位「现在人在哪步运」。
- **专题深入**是指路行：概览只给骨架，深入内容靠功能参数（见
  [commands.md](commands.md)），给了哪个就追加哪段详版。

概览里有时还会出现【出生地解析】提示——说明城市名做过容错解析或有同名歧义，**看到就
留意**（歧义会列候选，确认或改用 `--lng`）。

## 换着花样给输入

出生信息不总是「公历 + 钟表时间 + 城市」四件齐整，常见变体：

```bash
# 只有农历生日（闰月加 --leap）
node scripts/purple-star.ts astrology \
  --lunar 1987-10-23 --time 10:30 --city 杭州 --gender male

# 只知道时辰名，不知道几点几分（--branch 0-11，0=子 … 11=亥；12=晚子时）
node scripts/purple-star.ts astrology \
  --date 2011-06-24 --branch 5 --gender male --lng 116.4

# 不知道城市，只知道大致经度
node scripts/purple-star.ts astrology \
  --date 2011-06-24 --time 07:45 --gender male --lng 116.4

# 只有省名（按省会计；省市连写如「山东青岛」也能识别）
node scripts/purple-star.ts astrology \
  --date 2011-06-24 --time 07:45 --gender male --province 山东
```

几个默认行为，知道就行：

- **城市名容错**：`杭州` / `杭州市` / `浙江省杭州市` 都能解析；同名歧义会报候选。
- **真太阳时自动校正**：给了 `--city` / `--lng` 就按经度校正；校到跨午夜会自动顺延/
  回退出生日期，并在输出里写明——这是正确行为，不是 bug。
- **夏令时自动回拨**：1986–1991 年间中国的夏令时区间自动减 1 小时；出生证明上的时间
  已经自行减过的，加 `--no-dst` 关掉。
- **均时差默认不计**：需要把 ±16 分钟的均时差也算进真太阳时，加 `--eot`。

晚子时（23:00–23:59 出生）是特殊口径，会排出两张不同的盘，务必读
[faq.md](faq.md) 的「晚子时」一节再决定怎么给。
