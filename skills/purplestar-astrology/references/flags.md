# 参数面细则

`SKILL.md` 只列高频旗标；本文件是完整参数面，以及两个**不会报错、但会静默给出错误结果**的陷阱。

## 出生信息参数

`--date` / `--lunar`（+`--leap`）/ `--year`·`--month`·`--day`；`--time` 或 `--branch 0-12`、`--late-zi`、`--eot`；`--gender`（**必填**）；`--lng` / `--city` / `--province`；`--name`。

## 输出选项

`--json`、`--liuyue <农历月>`（配合 `--sihua` / `--liunian` 出流月四化节）。

## analyze 专题旗标族（可叠加）

默认（不带任何专题旗标）只出**精简概览**：命盘总览 + 口径提示 + 运限速览一行 + 专题指路。
给了哪个专题旗标就**只追加**该专题的详版：

| 旗标                | 形态         | 内容                                                                                                          |
| ------------------- | ------------ | ------------------------------------------------------------------------------------------------------------- |
| `--info`            | 开关         | 基本信息：性别 / 经度 / 钟表与真太阳时 / 农历 / **节气与非节气四柱** / 五行局 / 命盘类型 / 命主·身主·斗君·身宫。四柱仅为出生时刻记录，**不做八字论命** |
| `--geju`            | 开关         | 格局识别（判词 + 成立/加分/破格 + 出处）                                                                      |
| `--sihua`           | 开关         | 生年 / 流年（/ 流月）四化落宫 + 生年×流年**同星引动**                                                          |
| `--liunian [年]`    | 值可选       | 流年专题：流年命宫（**年支所在宫**，三合派不重排）+ 三方四正会照 + 四化落点（★ = 入流年三方）+ 与当前大限三方的对照。裸开关 = 当前年 |
| `--daxian [虚岁]`   | 值可选       | 十年大运：十二年运时间轴（每步附主星）+ 指定限三方四正与生年四化落点 + **限内十年逐年对照**（流年命宫 + 小限）。裸开关 = 当前虚岁 |
| `--xiaoxian [虚岁]` | 值可选       | 小限专题：小限宫 + 三方四正 + 十二宫岁数分布（虚岁 1–120）+ 与流年命宫同宫/对宫关系。裸开关 = 当前虚岁          |
| `--focus <宫名>`    | 值必填       | 宫盘分析：宫详表 + 对宫 + 三方四正会照星曜 + 生年/流年四化落宫 + 大限年龄段与流年/小限引动                      |

`--daxian` / `--xiaoxian` 的值域是 **1–120 虚岁**，越界报错（不静默兜底）。

## `--focus` 的宫名口径

用本项目口径（倪师《天纪》），十二宫统一带「宫」字：

> 命宫、兄弟宫、夫妻宫、子女宫、财帛宫、疾厄宫、迁移宫、**交友宫**、官禄宫、田宅宫、福德宫、父母宫。

第 8 宫是「**交友宫**」（排盘引擎 iztro 内部叫「仆役」，那是上游口径，**不要照抄**）。

`--focus` 会对输入先做一次归一化，下列写法都命中同一宫，可任选：

- **全名**（`--focus 交友宫`）
- **去「宫」字的简称**（`--focus 交友`）
- **iztro 旧写法**（`--focus 仆役` / `--focus 仆役宫`）

另外也接受**地支名**（`--focus 巳`）—— 注意它匹配的是「地支为该字的那一宫」，**不一定是命宫**。

都匹配不上才会报错，报错信息里会列出该盘实际的十二宫名。

## ⚠️ `--liunian` 勿写成 `--year`

后者是**出生年的回退参数**。两者同时给出**不会报错**：

> 流年取 `--liunian`；而一旦给了 `--date` / `--lunar`，`--year` 就被静默忽略，不会有任何提示。

也就是说，`--date 1990-05-15 --liunian 2026 --year 1985` 里的 `--year 1985` 是死参数，
而 `--lunar 1988-06-26 --year 1985` 里的 `--year` 又会被 `--lunar` 覆盖。
**要表达「看某年的流年」，只用 `--liunian`。**

## 完整帮助

```bash
node scripts/purple-star.ts help
```

`help` 渲染的参数段由 `scripts/cli/args.ts` 的 `FLAG_GROUPS` 派生，与解析器同源——
**它列出的就是本技能的全部合法旗标**，本文件不重复维护一份清单。

⚠️ 「本技能的」不是废话：三个 skill 各有各的声明表（2026-09-27 断派生关系后互不相干——
本技能是 `cac` 驱动的完整骨架，另两个用 Node 内置的 `util.parseArgs` 各写各的）。本技能实际认哪些
旗标由 `scripts/cli/flag-scope.ts` 声明。写出来不在作用域内的旗标（如合盘的 `--a-*` / `--b-*`、
古籍检索的 `--limit`）既不注册进 `help`，也会被**直接拒掉**，不是静默忽略。
