# 排障：合盘 skill 脚本报错对照表

本文件是 `SKILL.md` 的延伸——**遇到报错或异常输出时才读**，正常解读流程用不到。

## 启动期报错

| 报错                                                | 原因与处理                                                                                                                                           |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `[ziwei 启动失败] 找不到排盘内核`                   | skill 目录不完整，`<skill>/scripts/` 下的内核缺失（拷贝时漏带）。从源仓库补回 `ziwei/` 内核目录，或用 `ZIWEI_ROOT=<含 ziwei/ 的目录>` 指定内核位置。 |
| `[ziwei 启动自检失败]`                              | 内核被重构、关键导出改名或删除。核对 `scripts/cli/` 各模块的 import 列表与 `scripts/ziwei/` 的实际导出是否对得上。                                   |
| `Cannot find module 'iztro'` / `'lunar-typescript'` | 依赖未装。**看报错里的「当前内核根」**，在该目录下 `npm install`。                                                                                   |
| `registerHooks is not a function` 或 TS 语法报错    | Node 版本过低，需 ≥ 22.15（本项目开发环境为 v26）。                                                                                                  |

## 确认跑的是哪一份内核

`purple-star.ts` 按**两级优先级**定位内核 —— `ZIWEI_ROOT` 环境变量优先，未设则用技能自带的 `<skill>/scripts/`。

`selftest` 输出的**第二行**（形如 `内核根：<路径>`）就是当前生效的那一份，交付解读前据此核对。

## 参数报错

| 报错                                                             | 原因与处理                                                                                                     |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `缺少性别：需 --a-gender male\|female`                           | 没给该方性别，或取值不是 `male` / `female`。性别决定大限顺逆，**不要替用户猜**，直接追问。                     |
| `--a-date：\`a-\` 前缀只有 synastry 命令认……当前命令是 selftest` | 把出生信息旗标给了一个不排盘的命令。`selftest` 只做回归自检，不接受任何出生信息——改用 `synastry`。             |
| `未知参数 --dtae。最接近的是 --date。`                           | 旗标拼错。注意提示里给的是**剥掉 `a-` / `b-` 前缀之后**的名字，所以看到 `--date` 时，实际要写的是 `--a-date`。 |
| `未收录城市`                                                     | 城市名不在内置表里。改用 `--a-lng` / `--b-lng` 直接给经度。                                                    |

## ⚠️ 不会报错的那一类（最需要主动排查）

**无前缀的出生信息旗标在 `synastry` 上既不生效也不报错。** `synastry` 读的是 `aDate` / `aCity` 这些带前缀的键，写成 `--date` / `--city` / `--eot` / `--late-zi` 时它们全都读不到，脚本按默认值排盘、一个字都不说。

实测后果：`--a-city 喀什` 漏成 `--city 喀什` 后，甲方从「巳时 · 火六局 · 命宫子破军」变成「卯时 · 土五局 · 命宫寅廉贞」——**整盘全变**。

自查方法：看输出里的「真太阳时校正」栏。**校正量为 `+0 分` 而用户明明给了出生地**，就是漏了前缀（东经 120° 附近的城市例外，那里校正量本来就接近 0）。补上前缀重跑，别拿这张盘解读。

唯一有效的无前缀旗标是 `--json`。其余描述出生信息的旗标，每一个都必须带 `a-` 或 `b-`。

反方向**会**报错：`--a-date` 用在 `selftest` 上会被明确拒绝——所以「漏前缀不报错」是单向的，不能靠报错反推自己写对了。
