# 紫微斗数古籍原文检索

本 skill 只做一件事：在**三部紫微斗数原典**里全文查句，把原文与出处原样交给你。

**它不排盘、不断命。** 拿到原文之后怎么解读，属于 `purplestar-astrology`（排盘解读）与 `purplestar-synastry`（合盘）两个 skill。用户若要的是「排一张盘」或「解读我的命盘」，本 skill 帮不上忙，请转过去。

## 路径约定

本 skill 的根目录就是 **SKILL.md 所在目录**，其下是 `scripts/`（CLI + 古籍数据）、`package.json`。**它零依赖**：参数解析用的是 Node 内置的 `node:util` 的 `parseArgs`，故拷进 `~/.claude/skills/` 直接就能跑，**不需要 `npm install`**。

古籍内核（`scripts/classics/`）**只住在本 skill 里**：2026-09-27 拆 skill 时随 `classics` 命令从 `purplestar-astrology` 搬来，源里已没有这个目录。所以它没有「改源再同步」这回事——要补录古籍、修检索逻辑，就在本 skill 里改。

下文所有命令中的 `node scripts/purple-star.ts` 都**相对于 skill 根目录**。执行前 `cd` 到该目录即可：

```bash
cd <SKILL.md 所在目录> && node scripts/purple-star.ts classics --search 机月同梁
```

脚本本身可从**任意 cwd** 运行（内核按脚本自身位置定位，不依赖 cwd），所以 `cd` 只是为省去拼长路径。

## 用法

```bash
# 检索（最常用）
node scripts/purple-star.ts classics --search 机月同梁

# 控制命中条数（默认 15，上限之外不再扫描）
node scripts/purple-star.ts classics --search 紫微 --limit 5

# 不带关键词：列出已收录的书目与章数
node scripts/purple-star.ts classics
```

输出每条含「书名 · 章节」与命中处**前后各 40 字**的摘要，命中词裹在 `『』` 里。

### 匹配规则（决定了你该怎么用）

| 行为         | 说明                                                                       |
| ------------ | -------------------------------------------------------------------------- |
| **逐段落子串匹配** | 不分词，中文照原样搜即可。搜「机月同梁」会命中含这四个连续字的段落         |
| **大小写敏感**     | 不做大小写折叠（对中文无影响，搜英文缩写时留意）                           |
| **不做繁简转换**   | 繁体检索词**匹配不到**简体原文。搜不到时先换成简体再试                     |
| **只搜原文**       | 不搜译文与注，命中摘要给的是原文本身                                       |
| **计数单位是段落** | 同一段里命中词出现多次也只算一条，不要用命中数推断出现频率                 |
| **无相关度排序**   | 纯文档顺序（书序 → 章节序 → 段落序），凑满 `--limit` 立刻停 —— 想看全就调大上限 |

⚠️ `--limit` 传非正整数、或写了 `--limit` 却没跟值，会被**明确拒绝并说明是参数问题**，不会静默返回空结果。

## 已收录

骨髓赋、紫微斗数全集、紫微斗数全书三部。**书目与章数以 `classics` 无参数运行的输出为准**（那里由数据实时统计），不要凭记忆说某书有多少章。

引用原文时**一并给出书名与章节**（输出里就有），不要只丢一句光秃秃的原文 —— 用户核对时需要出处。

## 命令速查

| 命令                     | 用途                                 |
| ------------------------ | ------------------------------------ |
| `classics --search <词>` | 古籍原文检索（不带关键词则列出书目） |
| `selftest`               | 回归自检（末行自报项数）             |

完整帮助：`node scripts/purple-star.ts help`。
本 skill 只认 `--search` / `--limit` 两个旗标，help 的参数段也只会列出这两个 ——
出生信息那些旗标属于排盘类 skill，写在这里会被直接拒掉（不是静默忽略）。

## 若脚本报错

- `[ziwei 启动失败] 找不到古籍内核` → skill 目录不完整，`scripts/classics/` 缺失（拷贝时漏带）。从源仓库补回该目录，或用 `ZIWEI_ROOT=<含 classics/ 的目录>` 指定。
- `registerHooks is not a function` 或 TS 语法报错 → Node 版本过低，需 ≥ 22.15。
- 搜不到你以为该有的句子 → 先按上表逐条排查：**是不是繁体？是不是只搜了原文？** 再确认该书确实收录（`classics` 无参数运行看一遍）。
