# Spec Delta

## Purpose

约束「主场登记」的登记权威：本板块核心论断全文的**主场登记**（把该文的语义主场板块名记入装
配状态，供三方联动复现处降级指引）以装配层预扫描为唯一实现，渲染层不再携带第二份登记实现。
区别于「论断全文首现原则」（管全文在报告内唯一）与「双主星主场展开」（管首现板块 = 语义主
场），本 requirement 管的是「谁在何时登记」的单一性，以及预扫描与渲染取材之间等价前提的守卫。

## ADDED Requirements

### Requirement: 主场登记单一权威

「本板块核心论断的哪些全文登记主场」SHALL 以装配层预扫描（`getTopicMainContentTexts`）为唯一
实现；`getTopicReport` 渲染路径 SHALL NOT 对本板块主星全文（第一主星与第二主星的核心论断全
文）另行登记。预扫描与渲染取材的等价前提——核心论断全文与 `AnalysisOptions` 四字段（视角 /
流年 / 流月 / 大限下标）无关——SHALL 由对拍断言守卫。三方联动「渲染时发现他星全文」的首现登
记与四化注首现登记是不同协议，SHALL 维持原状、不受本条约束。

#### Scenario: 预扫描与渲染展开对拍

- **WHEN** 对固定样本盘集的每个主题，分别取预扫描清单（`getTopicMainContentTexts`，缺省视角）
  与渲染侧取材（`makeContext` 带非缺省 `AnalysisOptions` 后 `buildOverviewMaterial` 的核心论
  断全文集）
- **THEN** 两侧集合逐字相等（含空宫等无内容主题的空集），与视角选项取值无关

#### Scenario: 渲染路径不登记主星全文

- **WHEN** 以全新去重表对固定样本盘集逐主题执行 `getTopicReport`，检查登记进表的键集合
- **THEN** 该主题的预扫描全文不出现其中（三方联动对他星全文与四化注的登记不受此限——它们不
  是本板块主星全文）

#### Scenario: 主场落点 0 落空

- **WHEN** 对固定样本盘集生成 `--report` 全盘报告
- **THEN** 每条预扫描全文恰在其语义主场板块的「核心论断」节出现，且全报告恰出现一次（复现处
  为徽标加指引行）

#### Scenario: 第二登记点回归即红灯

- **WHEN** 渲染路径重新对本板块主星全文登记，或核心论断全文改为随 `AnalysisOptions` 视角变化
- **THEN** 上述对拍断言失败（非零退出），不静默产出板块序相关的首现漂移或指引目标翻转
