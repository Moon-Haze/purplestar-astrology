# code-style Delta

## ADDED Requirements

### Requirement: 注释占比上限

手写 `.ts` 源文件的注释占比 SHALL NOT 超过 **30%**。占比定义为「注释行数 / 非空行数」，分母为文件内所有非空行，分子为整行 `//`、`/* */`、`/** */` 的起止行及其 `*` 续行，含行尾注释的整行不重复计数。`30` 为单一登记阈值，调整须改本 spec，不得各文件各自为政。**本 requirement 不设按文件或按类别的豁免清单**；生成物由「改生成器重导」纪律管辖，本就不手工维护。

#### Scenario: 阈值违反

- **WHEN** 某个手写 `.ts` 的注释占比经度量脚本统计 > 30%
- **THEN** 该文件判为违规，需精简或外置注释至 `docs/code/` 后复测，直到占比 ≤ 30%

#### Scenario: 度量口径可复现

- **WHEN** 对同一文件用同一度量脚本跑两次
- **THEN** 两次输出的注释行、非空行与占比完全一致；阈值 30 由脚本从本 spec 登记值读取，不写死在脚本里

#### Scenario: 存量超标文件

- **WHEN** 文件在本 requirement 生效前已超标
- **THEN** 不设豁免条目，后续每次改动该文件时同步收敛占比至 ≤ 30%；未改动期间由度量报告如实列报，不伪装达标

#### Scenario: 阈值调整

- **WHEN** 需要把 30% 改为其他数值
- **THEN** 只改本 spec 的登记阈值，度量脚本随之读取新值，不出现多套口径
