# Proposal · 魁钺贵人表键域漂移修复 + 守卫登记（评审 2026-11-18 候选 1）

## Why

`KUI_YUE_GUIREN_MAP`（魁钺贵人倾向细分表，`scripts/analysis/data.ts:2687-2706`）的
十二个宫名键是**紧凑形 + 旧口径**（`命宫` / `兄弟` / … / `仆役` / `官禄`），而唯一
消费点 `scripts/analysis/views/patron.ts:38/:48` 拿运行时展开形 `Palace.name` 直查
（`PALACE_NAMES_ORDER` 同域：`兄弟宫` / `交友宫` / `官禄宫`…）——十二键只有 `命宫`
能命中，其余 11 键运行时永远 miss，`map?.kui` 可选链静默吞掉。后果：天魁 / 天钺落
其余十一宫的任何盘，「五点六、魁钺贵人倾向细分」整段不出内容——**11/12 的分支
空间功能性失明**，不是文案瑕疵。

这正是 AGENTS.md「键域口径」点名的缺陷类（数据表键与运行时键不一致导致静默 miss）
在守卫网外的**同型复发**（2026-10-24 评审 S1 修过一次内容键表，本表漏在网外）：
typecheck 查不到（表类型是 `Record<string, …>`，键不进类型域）、invariants 宫名键域
互证没登记这张表、可选链吞 miss 三个放大器让它活着。

## What Changes

1. **改键**：`KUI_YUE_GUIREN_MAP` 十二键改展开形，与 `PALACE_NAMES_ORDER` 同域
   （`兄弟`→`兄弟宫`、`夫妻`→`夫妻宫`、…、`仆役`→`交友宫`、`官禄`→`官禄宫`；
   `命宫` 已带宫字不变）。**断语内容逐字不动**。
2. **守卫登记**：`test/invariants.test.ts` 的宫名键域互证断言补登记本表——键域
   断言（超域键报红）加第四张表的循环；完备性断言（十二宫齐）加本表键数对拍
   `PALACE_NAMES_ORDER.length`。**并入现有两个 `it`，不新增测试项**（「内核层测试
   项数」报警器零扰动）。
3. **spec 补全**：quality-gates「分析数据表键域互证」requirement 的守卫面枚举补入
   魁钺贵人倾向表 + 全域表完备性条款；顺带把该 requirement 里「主题断语手册的主星
   键集」退役残留措辞修正为实态（断语手册已下线，守卫实态是星曜内容 / 星曜简述
   两表与内核星表互证——与 `test/invariants.test.ts` 现行断言一致）。
4. **生成物重导**：若 DEMO 样例盘的天魁 / 天钺落宫命中新分支，`npm run cli-samples`
   重导 `docs/cli-samples.md`（改生成器 + 重导，不手改产物）。

## Impact

- 代码：`scripts/analysis/data.ts`（十二键名，断语零改动）、`test/invariants.test.ts`
  （两个现有 `it` 的覆盖面延长）。**analysis 知识内容层，零排盘内核改动**（ADR-003
  分层红线不触及；`npm test` 排盘基准 300 条对拍不受影响——基准只管排盘字段）。
- 行为变化是**预期的内容扩展**：魁钺落其余十一宫的盘开始出细分文案（缺陷修复，
  非等值收敛）。
- spec：`openspec/specs/quality-gates/spec.md` 经本 change delta 折回。
- 消费点 `patron.ts` 零改动——直查代码本就正确，坏的只是键域。

## 不做什么

- **不动断语内容一个字**——十二键的 kui/yue 断语逐字保留（引文纪律：既有内容原样
  迁移，不新增「倪师 + 引号句」形态，不动 `analysis/grades.ts` 登记表）。
- **不做候选 9**（soul-summary 两表 + synastry 表外键的键集守卫补网）——它是键域
  守卫网的姊妹篇但属独立候选，另行提案；本 change 不夹带。
- **不动 `patron.ts` 消费逻辑**——`map?.kui` 可选链在键域正确后是「无断语宫」的
  合法语义（本表语义即全十二宫有断语，守卫完备性断言钉住后可选链仅防未来缩表）。
- **不引入 `as const` 类型化**（否决，理由见 design.md）。
- **不动 `PALACE_NAMES_ORDER`**——运行时宫名域真相源不动。

## 被否决的备选方案（留档）

- **只删 11 条死键留 `命宫` 一键**：否决。表语义是天魁 / 天钺落任何宫都有贵人倾向
  断语（倪师体系魁钺为「贵人星」，落宫即论），删键 = 内容缩水且与完备性守卫矛盾。
- **改 `patron.ts` 做紧凑形归一映射再查表**：否决。在消费点加一层「展开形→紧凑形」
  反向换是为坏数据擦屁股，复杂度搬家而非消灭；且换不回旧口径 `仆役`（运行时已是
  `交友宫`），归一映射对第 8 宫根本写不出来。
- **新增独立 `it` 登记守卫**：否决。并入现有两个 `it` 即可完整表达，不新增测试项
  数，「内核层测试项数」报警器零扰动；独立 `it` 需同步 `test/README.md` 层表并
  说明项数变动理由，徒增登记负担。
