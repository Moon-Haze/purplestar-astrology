# Proposal

## Why

现行 `README.md` 的视角是「向 AI 助手与维护者解释本仓」：开篇即「供 AI 助手调用」的
机制自述，第一屏被渐进披露 / 骨架 / 不拍平等**内部设计与维护者警告**占据，而一个
GitHub 访客来看 README 时想要的东西——这个项目能做什么、输出长什么样、怎么装、
怎么用、什么许可——大多缺失或被淹没。README 应是项目的门面（给人看），不是
第二份 SKILL.md（给 AI 读）。

## What Changes

- **读者重定位**：主受众 = GitHub 访客与潜在使用者（人），次受众 = 想装进 AI 助手的
  用户，维护者视角内容下沉。全文按「是什么 → 能做什么（含示例）→ 怎么装 → 怎么用
  → 项目地图 → 来源与许可」的门面结构重排。
- **补齐访客内容**：
  - 三域能力清单（排盘 / 合盘 / 知识检索各自能干什么，普通词说清）；
  - CLI 实际输出示例节选（虚构示例出生信息，与仓内文档同款口径）；
  - 命令速览（三命令 + 最小示例，`help` 指路保留）；
  - 仓库顶层目录一览（一句话地图）；
  - 许可与语料授权说明（天纪语料 CC BY-NC-SA）。
- **下沉与收敛 AI 向内容**：SKILL.md 骨架 / 渐进披露论述收敛为一句话 + 指路；
  「`scripts/` 不拍平」的数百处 import 警告、「字节可复现」的 zlib 实现细节、「数据
  来源」代码模块地图等维护者内容移出主文（指路 `docs/` 与 `AGENTS.md`）。
- **保留全部硬承诺**（逐项核对）：只拷 4 项 / 不 `cp -r`（641 MB 坑）、zip 顶层名
  与 frontmatter `name` 一致、Node ≥ 22.18、落位 `npm install` + selftest 自检、
  sha256 可复现、上游 ziwei-doushu 致谢。
- **计数不写死**：「160/160」「131 条目」「约 1.2 MB」等会漂移的数字改为定性表述
  （「应全绿」），或注明日期快照。

## 不做什么

- **零代码改动**：不触 `scripts/` / `SKILL.md` / `references/` / 测试——README 在
  分发件外，本变更既非内容扩展也非内核改动，不跑内核回归（引文守卫例外，见 tasks）。
- **不动任何 spec**：`distribution` 等 spec 对 README 无内容承诺（唯一关联是
  「不进分发件」），故本变更声明 `skip_specs: true`，无行为 delta。
- **不引入引号引文**：README 在引文守卫的 `.md` 扫描面内，正文不放「倪师 / 倪海厦 +
  引号句」形态的内容，体系口径只做指路——不新增 `grades.ts` 登记。
- 不新增徽章 / 外链营销内容，语言与格式沿用仓内简体中文 + Markdown 口径。
