# Proposal

## Why

2026-11-17 变更（527c1ec）只把组合矩阵的**跳过条件**改为派生（前案 design.md:116-121
D6），矩阵的两根轴本身仍是手抄清单——`scripts/cli/args/table.ts:488-491` 的注释
「命令侧的被吞检测、消费放行、--info 上级梯、优先级文案与 report.test 组合矩阵全部
从本清单派生」对矩阵半边今天为假：

1. **分支轴手抄**：`test/report.test.ts:250` 硬编码四元组
   `[["--info"], ["--palaces"], ["--topic", "love"], ["--report"]]`——今日恰与
   `table.ts:493-508` 的 `EXCLUSIVE_BRANCHES` 四条重合，**第 5 条分支加入声明表不会
   进矩阵**；
2. **旗标轴手抄**：`report.test.ts:251-255` 硬编码 4 格（monthly / daily / hourly /
   view），而被吞域 `SHADOWABLE_KEYS` 有 13 项（`scripts/cli/selftest/args.ts:176`
   快照 S）——view 2026-11-11 入域时就是手工补进这份旗标清单的；
3. **allow 方向手抄**：`report.test.ts:269-273` 又手抄一遍 topic 的消费白名单
   （yearly / monthly / view），与 `table.ts:497` 的 `consumes` 成第二份副本。

它使前案 design.md:128-130 宣称的接缝判据「命令侧与测试面零协同」只在跳过维度
成立——新增/退役独占分支或 shadow 旗标仍要协同改 report.test 三处；也使前案
design.md:112-114 接受「清单序与分发序两序并存」的理由（「被不变量 + 行为钉点双向
看住」）在第 5 条分支到来时失效——行为钉点只覆盖手抄的四条分支。
`selftest/args.ts:240-267` 的声明完整性断言只守声明表内部一致性，守不到矩阵覆盖面。

摩擦不是预测而是已发生的账（git 实证）：d6827fc 补 daily/hourly 动了四处、
da4a449 补 view 动了六处，「同一根因数日内两次 change」——手抄漏格正是根因，矩阵轴
是这套手抄在测试面的最后残留。deletion test：这三份手抄副本（分支轴 / 旗标轴 /
allow 白名单）正是 report.test.ts:232-235 注释宣称已消灭、table.ts:491 注释宣称
不存在的那份清单；维持手抄 = 复杂度集中在「人记得同步三处数组」，派生收拢回单一
真相源，删掉派生即回到必然漂移的手抄。

## What Changes

- **分支轴从 `EXCLUSIVE_BRANCHES` 派生**：矩阵外层循环改为遍历声明表清单；`--topic`
  需要主题值这类探针 argv 用一张小映射补齐，映射缺某分支名时断言当场红——
  「新分支未入矩阵」从静默变当场红（缺名守卫）。
- **旗标轴从 `SHADOWABLE_KEYS` 派生**：内层循环改为遍历被吞域；值形态旗标
  （kind: value）的合法样本值用一张小映射补齐（switch 不带值），缺名守卫同款；
  自指格（flag === branch）跳过——本会话实跑证实该格在端到端触发的是 parse 层
  参数判重文案（`--topic love --topic love` → 「参数 --topic 重复给出」），不是
  被吞文案，不跳过会误报。
- **allow 方向从清单该条目 `consumes` 派生**：凡 `consumes` 非空的分支自动进
  allow 断言循环（探针值同用旗标值映射），`table.ts:497` 的白名单成为唯一表态处。
- **矩阵由抽样升为封闭枚举**：4 分支 × 13 旗标 = 52 格，跳过 3 自指格
  （topic/report/info 自指；palaces 标 `noShadow` 有意域外、不产生该格）+
  3 放行格（topic × yearly/monthly/view，走 allow 断言）+ 1 bespoke 格
  （report × view，既有 it 的子串钉点分管）后 **45 格走通用「不会生效」断言**，
  合 allow 3 格共 48 格，全部进程内直调（命盘缓存命中后秒级）。声明表任何增删
  自动跟随，报告格数自报、不写死。
- **新增格先探针证实再落地**：本会话已对全部 48 格实跑探针，45 格通用断言
  （点名 + 「不会生效」子串）与 3 格 allow 断言（主题论断正常出、无误伤报错）
  **逐格全绿**——封闭枚举落地即绿；若未来有格不成立，那是新发现的次序缺陷，
  属净增信息，按失败可见性处理为修复项而非加跳过格。
- **不做什么**：
  - 不动 `table.ts` / `astrology.ts` / `selftest/args.ts` / 任何 CLI 行为——
    运行链路零文件改动，对外行为逐字节不变是结构保证；
  - 不动 selftest 的声明完整性断言与 shadow 穷尽性守卫（职责分工不变：声明表
    内部一致性归 selftest，行为封闭枚举归 report.test）；
  - 不新增测试文件（无 `test/README.md` 层表与 `test/lib/run.ts` LAYERS 登记义务，
    内核层测试项数不动，AGENTS.md:311-312 越界报警器无感）；
  - 不把 `palaces` 扫进旗标轴——它标 `noShadow` 是有意域外表态（最高优先级、
    永不被吞），旗标轴跟 `SHADOWABLE_KEYS` 域声明走；
  - 不顺带做 `--info` 上级梯行为钉点（5 号发现）——它可自然填入同一派生骨架，
    留作后手，本变更 diff 面保持最小；
  - 不做格级逐字节文案对拍——includes 双子串是可维护的契约面，逐字节对拍会把
    文案措辞冻结进测试，与「测试面零协同」目标自相矛盾。

### Modified Capabilities

- `quality-gates`：新增「独占分支组合矩阵封闭派生」需求——report.test 的独占分支
  × 功能参数组合矩阵，其两根轴（分支轴、被吞旗标轴）与 allow 方向 SHALL 由声明表
  单一派生、构成封闭枚举，新分支/新旗标未进矩阵 SHALL 当场红。与 2026-11-17 落地的

## Impact

- **代码**（1 个文件）：`test/report.test.ts` 既有 describe 内改派生（三根轴 +
  skip 规则补自指项），**无新增测试文件**、无运行链路文件改动。
- **行为变化方向**：无。CLI 输出、退出码、报错文案零变化；唯一语义变化是测试
  覆盖面从 16 格手抄抽样升为 48 格封闭枚举（本会话逐格探针证实全绿）。
- **与 AGENTS.md 约束**：无冲突——不触内核与知识内容分层（ADR-003）、不动冻结
  内核契约、不新增插件注册面；「计数类事实不写死」反而被本变更强化（矩阵格数
  自报）。
- **验证义务申报**（按 config.yaml 三档）：**内容扩展档**（纯测试面，运行链路
  零改动、不重跑内核基准对拍的理由是 `npm test` 本身就是被改对象）——但三件套
  照跑从严：`npm run typecheck` 0 错误；`ZIWEI_NO_CACHE=1 node scripts/purple-star.ts
  selftest` 全绿且项数与基线一致（selftest 面零改动）；`npm test` 全绿（新增
  `it` 数为零，项数不变；矩阵 it 内格数从 13+3 升为 45+3，it 自报）；新增行跑
  `npm run lint` / Prettier 只对改动行。

## 被否决的备选方案

1. **半封闭：只派生分支轴、旗标轴保持手抄**——view 2026-11-11 入域时手工补格的
   教训说明旗标轴才是高频漂移轴（被吞域 13 项对 4 格，扩被吞域是本域最高频的
   改动类型），半封闭留着同一根因，deletion test 不过（重复没除尽 = 复杂度仍集中）。
2. **探针映射内联在循环里、不设缺名守卫**——新分支/旗标加入声明表后矩阵静默漏格，
   恰是本变更要消灭的失败模式；缺名守卫把「未入矩阵」从静默变当场红，与失败可见性
   （AGENTS.md:251-252）同构。
3. **拆独立 `test/matrix.test.ts` 并登记层表**——矩阵语义上就是 report.test 既有
   describe 的封闭化，拆出去 = 复杂度搬家（deletion test 不过），还白增层表与
   LAYERS 登记义务和内核层项数对账成本。
4. **把 `palaces` 也扫进旗标轴求「对称」**——`palaces` 标 `noShadow` 是 2026-11-11
   穷尽性守卫的显式表态（最高优先级分支、永不被吞），域外即其声明；旗标轴跟
   `SHADOWABLE_KEYS` 走，越域扫描是把域声明当耳旁风。
5. **并入 5 号发现（--info 上级梯行为钉点）**——证据虽强，但它不消除重复、做完
   没有后续改动变容易，是纯保险；矩阵封闭后它可复用同一派生骨架自然后手。并入只让
   本变更 diff 面翻倍、稀释评审注意力（最小 diff 纪律）。
6. **格断言升级为逐字节文案对拍**——通用文案是「点名被吞参数 + 固定指路」模板，
   includes 双子串已可维护；逐字节对拍把措辞冻结进测试，文案演进须协同改测试，
   与本变更「测试面零协同」的目标自相矛盾。
