# 知识地图 —— 六仓血统与许可

> [!info] 手写页，重导不覆盖
> 描述紫微斗数多根工作区的数据/知识供给关系；分区内容清单见各 `_索引.md`。

本仓（purplestar-astrology）是六仓中唯一的**产品仓**，其余五仓为它供给数据与知识。
本 vault 取的是「知识链」的精选内容：

```text
知识链：purplestar-voice ──→ nihai-tianji-corpus ──→ 本仓 corpus/
        （视频转文字）        （语料结构化 4886 条）    （TS 数据快照）
基准链：ziwei-doushu ──→ ziwei-samples-toolkit ──→ purplestar-db-slim
        （参照引擎）       （518,400 条排盘样本）    （DuckDB 工具）
```

## 血统说明

- `10-`~`50-` 分区的判语与本仓 `scripts/corpus/data/tianji.ts`（1125 条快照）同源，
  均来自语料库 `data/entries.jsonl` 的紫微五册；要更新判语，先在语料库侧改，
  再重导本仓快照（`npx tsx tools/corpus/import-tianji.ts`）与本 vault（`npm run notes:export`）。
- 每条判语带 B 站视频 bvid + 分 P + 秒级时间戳，回放链接即溯源凭证。
- `60-方法/引文真伪分级` 是 toolkit 对全部「倪师引语」的五级核对（verified /
  traditional / suspect / fabricated / methodology）——引用判语前先看分级。
