# 紫微斗数知识库（Obsidian Vault）

本目录是紫微斗数多根工作区的**精选知识 vault**——把六个仓库里的紫微斗数知识整理成
Obsidian 笔记。在 Obsidian 中「打开文件夹作为库」选择本目录即可使用。

## 入口

- [[00-索引/紫微斗数总览|紫微斗数总览]] —— 全库 MOC 主入口
- [[00-索引/知识地图|知识地图]] —— 六仓血统、来源与许可说明

## 分区

| 分区 | 内容 | 维护方式 |
| --- | --- | --- |
| `00-索引/` | 总览 MOC 与知识地图 | **手写** |
| `10-星曜/` `20-宫位/` `30-格局/` `40-四化/` `50-疾厄/` | 倪师原话判语（按主题聚合） | 脚本生成，勿手改 |
| `55-古籍/` | 全书 / 全集 / 骨髓赋节选 | 脚本生成，勿手改 |
| `60-方法/` | 引文真伪分级（生成）+ 体系口径（手写） | 混合 |
| `70-课程笔记/` | 课程视频的主题化总结 | 脚本生成，勿手改 |
| `75-主星论断/` | 产品仓 analysis 论断库（十四主星全量） | 脚本生成，勿手改 |
| `80-主题手册/` | 产品仓断语手册（14 主题 × 14 主星） | 脚本生成，勿手改 |
| `85-合盘断语/` | 合盘夫妻宫断语库 | 脚本生成，勿手改 |
| `90-模板/` | 判语卡模板 | **手写** |

## 维护

笔记由 `npm run notes:export` 从外部数据源仓生成，**同输入两次导出逐字节一致**；
要改内容请改数据源后重导，手改生成文件会被下次导出覆盖。
